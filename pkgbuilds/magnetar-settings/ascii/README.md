# Magnetar ASCII logos

The monogram — an M drawn as arch, cup, arch, with the star held in the cup —
at four sizes. All generated by `gen.py`; edit `marks/*.txt` (or the SVG, for
`detailed`) and re-run it rather than editing these files.

| file | what |
|---|---|
| `magnetaros-detailed.txt` | block-art mark rendered from the SVG + wordmark (57×18) — the fastfetch logo |
| `magnetaros-medium.txt` | outlined box-drawing mark + wordmark (57×14) |
| `magnetaros-simple.txt` | plain-ASCII mark + wordmark (57×10); safe on any console font |
| `magnetaros-tiny.txt` | 7×4 mark only (prompts, fetch panels) |
| `wordmark.txt` | wordmark alone |
| `*-color.sh` | same art in 24-bit colour: the logo's violet → cyan diagonal gradient, the star in ice white |
| `magnetaros-detailed.ans` | `detailed` with the colour pre-rendered, for fastfetch's `file-raw` logo |

`tiny`, `medium` and `detailed` use Unicode (box drawing, `●`, quadrant
blocks); `simple` is pure ASCII.

## Use

    sh magnetaros-detailed-color.sh            # print it
    sh magnetaros-simple-color.sh > /etc/motd  # login banner (needs truecolor terminal)

fastfetch: `fastfetch --logo-type file-raw --logo magnetaros-detailed.ans`.
neofetch: `--ascii "$(sh magnetaros-simple-color.sh)"`, or the plain `.txt` with `--ascii_colors 5 4 6`.

Colours are 24-bit truecolor. If your terminal is 16-colour only, use the `.txt` files and let the tool colour them.
