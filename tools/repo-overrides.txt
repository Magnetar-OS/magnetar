# Deliberate shadowing. Every entry here is a repository above Arch that is
# ALLOWED to be the source for a package Arch also carries.
#
# Format: repo:package, or repo:* for a repository whose entire purpose is to
# shadow Arch.
#
# Adding a line is a decision that part of the base system comes from that
# repository. It is not a way to quiet the audit. The list below was generated
# by running tools/repo-audit.sh against a live CachyOS install and recording
# what CachyOS actually overrides — not from guessing, and not from CachyOS's
# documentation, which does not enumerate it.
#
# Regenerate after a CachyOS repo change with:
#   tools/repo-audit.sh | awk '$1=="FAIL" && $4=="cachyos" {print "cachyos:"$2}'

# --- The optimised rebuilds ------------------------------------------------
# These exist to replace core/extra with x86-64-v3/v4 builds. Shadowing every
# name they carry is the entire feature.

cachyos-core-znver4:*
cachyos-extra-znver4:*
